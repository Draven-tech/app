Core Features
1. 🕵️ FraudWatch – AI-Powered Tamper Detection
How it works:

Users scan container seals or cargo photos at pickup/delivery.

TensorFlow.js model detects tampering (scratches, resealing, cargo mismatches).

Alerts Gothong HQ + stores tamper-proof logs (Firebase).

Demo Hook: Show a real-time comparison of a "clean" vs. "tampered" seal.

2. 🌀 TyphoonSafe – Disaster-Aware Routing
How it works:

Pulls PAGASA weather alerts (or mock API) for real-time typhoon/flood data.

Overrides gEasy™ routes with safer paths (highlighting avoided risks).

Demo Hook: Side-by-side maps: "gEasy’s route vs. our typhoon-safe detour."

3. 📦 PalletAI – AR Load Optimization
How it works:

Point phone at a pallet → AR overlay suggests optimal stacking.

Uses OpenCV.js to calculate weight distribution.

Demo Hook: Show a before/after pallet load (e.g., "AI saved 30% space!").
